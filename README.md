# 🎮 语塔攀登 (WordSpire) —— 英语口语 Roguelike 练习游戏

**语塔攀登 (WordSpire)** 是一款将 Roguelike 爬塔玩法与英语口语练习深度融合的创新 HTML5 网页游戏。玩家通过大地图规划路线，在应对小怪、精英及 Boss 战的过程中进行朗读与对话。游戏接入了专业的口语评测引擎与 LLM 分析大模型，将枯燥的口语练习转变为刺激的主动冒险。

---

## 🚀 项目亮点与核心功能

### 1. 仿《杀戮尖塔》分叉地图与智能导航 (Phaser 3 Engine)
*   **Roguelike 路线规划**：包含 8 层高度随机化的分支关卡树。玩家在爬塔过程中需要根据自身血量、金币以及背包道具自主选择前进方向。
*   **锁定关卡绝对保密**：所有未解锁（Locked）的后方关卡全部隐藏具体关卡类型与难度，并直接在节点中心生成一个复古的灰色像素锁，充分保留探索未知的新鲜感。
*   **高对比度视线指引**：地图路径连线采用三档加粗（已完成路径 `6px` 灰色；当前可用路径 `10px` 亮冰蓝色；未解锁路径 `5px` 深紫灰色），在任何分辨率下均清晰可辨。
*   **炫丽的当前可选节点特效**：可交互节点被赋予了**双重金色光圈波纹涟漪**、**三颗金色旋转星芒（`✦`、`★`、`✨`）**，以及平滑的**呼吸缩放与悬停放大（1.5倍）**动画。

### 2. 场景选择与针对性专属题库
*   在新游戏开始时，玩家可以在 **面试 (Workplace) / 点餐 (Restaurant) / 会议 (Meeting) / 随机 (Random)** 四个主题场景中进行选择。
*   进入游戏后，全关卡（包含小怪跟读、情境对话以及 Boss 战）的语料数据都会由该场景的专属题库动态供给，实现高契合度的针对性口语突击练习。

### 3. 专业发音评测与四色标记纠错渲染
*   **腾讯云 SOE 发音评测**：前端采集并上传用户的口语音频，通过后端高保真转码后送入腾讯云 SOE 口语评测引擎，获取精确至音素级的发音细节打分。
*   **MiniMax M3 LLM 语法及表达诊断**：使用大语言模型对用户发音识别文本进行语法校对，并推荐更地道、更符合语境的表达句式。
*   **四色富文本纠错技术**：
    *   🟢 **绿色**：发音与语法完全正确；
    *   🔴 **红色 + 下划线**：发音评分低于 75 分的单词，鼠标悬浮展示具体发音分数；
    *   🟡 **黄色 + 虚线下划线**：语法硬伤，悬浮展示原文及大模型修改意见与错误解析；
    *   🔵 **蓝色 + 斜体 + 点状下划线**：表达不地道，悬浮展示更优表达句式与推荐理由。

### 4. Boss 战实时语音双向对话 (WebSocket)
*   在各章节的终极 Boss 战中，开启了基于 WebSocket 协议的实时对话博弈。
*   玩家通过语音和 Boss 进行真实交流，大模型动态推理 Boss 响应文本并调用 MiniMax TTS 进行高拟真度回复，双向交互延迟压在 **1.5 秒**以内，带来沉浸式的人机语音博弈体验。

### 5. 游戏化 AI 导师总结评语
*   关卡结束跳转至总结页面时，后端根据玩家在整关中的累计表现、得分及评级（S/A/B/C/D/F），调用大模型实时生成极具鼓励性、游戏化风格的“AI 导师总结点评”，并针对性地提取出 1~2 个最急需突破的薄弱环节点。

### 6. 复古像素风 UI 与全分辨率自适应排版
*   **1.5倍字体放大**：针对复古像素字体较小、辨识度低的痛点，全局将字号、行高与边框进行了 1.5 倍等比例放大，且自动追加 `padding` 避免像素字体的底部裁剪。
*   **自适应防重叠布局**：重新规划了主界面、总结页与战斗界面的 UI 组件坐标，将血条、能量、金币、背包和计时按钮等做水平/垂直拉宽排布，确保在任何屏幕分辨率下都不会出现遮挡。

## 🛠️ 项目架构与目录结构

项目采用**前后端分离**的架构，前端通过开发服务器代理 `/api` 流量至本地运行的 Go 后端网关，确保 API 密钥与签名服务的安全性。

```
ai_language_learning_platform_xengineer_qiniucloud/
├── backend/                  # Go 后端源码
│   ├── cmd/
│   │   └── main.go           # 服务入口
│   ├── internal/
│   │   ├── api/              # API 路由与 handlers 注册
│   │   ├── config/           # 密钥配置文件加载 (secrets.yaml)
│   │   ├── handler/          # 业务 Handler (含评估、总结、WS 实时对话)
│   │   └── service/          # 第三方服务对接 (腾讯 SOE、MiniMax LLM / TTS)
│   └── go.mod
│
├── frontend/                 # Phaser 3 前端源码 (独立打包)
│   ├── public/
│   │   └── style.css         # DOM 覆盖物及按钮全局样式
│   ├── src/
│   │   ├── data/             # 场景化专属题库
│   │   ├── game/             # 关卡管理器与全局状态 GameState.js
│   │   ├── map/              # 地图生成器与地图渲染器 MapRenderer.js
│   │   ├── scenes/           # Phaser Scene 集合 (含 BattleScene, BossScene 等)
│   │   ├── services/         # 前后端交互 API 客户端
│   │   └── utils/            # 拦截器、Constants.js 常量配置
│   ├── index.html
│   ├── vite.config.js        # Vite 代理与打包配置
│   └── package.json
│
└── README.md                 # 说明文档
```

## ⚙️ 配置文件说明

在启动项目之前，需要准备并填写后台接口密钥。在 `backend/internal/config/secrets.yaml` 中配置您的密钥信息（模板如下）：

```yaml
minimax:
  api_key: "your-minimax-api-key"
  base_url: "https://api.minimax.chat/v1"
  model: "minimax-m3"
tencent:
  secret_id: "your-tencent-cloud-secret-id"
  secret_key: "your-tencent-cloud-secret-key"
  soe_region: "ap-guangzhou" # 推荐广州或上海
```

## 🚀 本地快速启动指引

### 1. 启动 Go 后端服务

确保本地安装了 Go 环境 (推荐 1.18+)，进入 `backend` 目录拉取依赖并运行：

```bash
cd backend
go mod tidy
go run cmd/main.go
# 当终端输出 [GIN-debug] Listening and serving HTTP on :8081 时，代表后端服务已成功拉起
```

### 2. 启动前端 Vite 开发服务

确保本地安装了 Node.js 环境，进入 `frontend` 目录安装依赖并运行：

```bash
cd frontend
npm install
npm run dev -- --port 8080
# 启动成功后，在浏览器中打开 http://localhost:8080/ 即可开始游戏
```
